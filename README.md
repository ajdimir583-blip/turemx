# Цифровой навигатор по наследию Мегино-Кangalасского улуса

Готовый учебный MVP на Python + Flask + SQLite. Включает публичный каталог, поиск и фильтры, карту Leaflet/OpenStreetMap, карточки объектов, ссылки построения маршрута и защищённую панель администратора с CRUD-операциями и публикацией/черновиками.

## 1. Запуск на Windows

1. Установите Python 3.10 или новее.
2. Распакуйте архив и откройте терминал в папке `megino_navigator`.
3. Создайте виртуальное окружение:

   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   ```

4. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

5. Задайте учётные данные администратора и секретный ключ:

   ```powershell
   $env:ADMIN_USERNAME="admin"
   $env:ADMIN_PASSWORD="Задайте-Свой-Сложный-Пароль"
   $env:SECRET_KEY="длинная-случайная-строка"
   ```

6. Запустите сайт:

   ```powershell
   python app.py
   ```

Откройте в браузере: http://127.0.0.1:5000

## 2. Запуск на macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export ADMIN_USERNAME=admin
export ADMIN_PASSWORD='Задайте-Свой-Сложный-Пароль'
export SECRET_KEY='длинная-случайная-строка'
python app.py
```

Откройте http://127.0.0.1:5000

## 3. Администрирование

Перейдите на `/login`. При первом запуске, если переменные окружения не заданы, используются временные данные:

- Логин: `admin`
- Пароль: `change-me-now`

**Обязательно задайте собственные `ADMIN_PASSWORD` и `SECRET_KEY` до любого размещения в интернете.** Если база уже создана, смена `ADMIN_PASSWORD` в окружении не изменит существующий пароль: для учебного сброса остановите сервер, удалите `navigator.db` и запустите приложение снова (это удалит все записи) либо обновите пароль отдельной административной процедурой.

Администратор может создавать, редактировать, удалять карточки, указывать координаты и переводить объект в черновик. Черновики скрыты от посетителей.

## 4. Наполнение каталога

В стартовой базе есть три демонстрационные карточки, чтобы интерфейс не был пустым. Они не являются проверенным справочником. Проверьте и замените описания, адреса, стоимость, контакты, сезонность и координаты через `/admin`.

Для отображения объекта на карте внесите широту и долготу. Расстояние от Якутска указывается вручную. Фотография задаётся публичной ссылкой на изображение.

## 5. Что подключено

- Flask — сервер и маршрутизация.
- SQLite — база данных, создаётся автоматически в `navigator.db`.
- Leaflet + OpenStreetMap — интерактивная карта (нужен интернет).
- Google Maps Directions URL — открытие маршрута для объектов с координатами.

## 6. Перед реальным запуском

Это готовый демонстрационный MVP, но не прошедший аудит production-сервис. Для публичного развертывания добавьте CSRF-защиту форм, ограничение попыток входа, HTTPS, резервное копирование базы, журнал действий администраторов, проверку внешних URL и загрузку фотографий через безопасное хранилище. Проверьте все туристические сведения и получите согласие владельцев объектов на публикацию контактов/фото. Для точного маршрута используйте проверенные координаты и сведения о сезонном состоянии дорог.
